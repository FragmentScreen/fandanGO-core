# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and inclusive environment for all contributors.

## Expected Behaviour

- Be respectful and considerate.
- Provide constructive feedback.
- Collaborate openly and professionally.

## Unacceptable Behaviour

- Harassment or discrimination.
- Personal attacks or abusive language.
- Any behaviour that negatively impacts participation.

## Enforcement

For conduct-related concerns, please contact the project maintainers via [GitHub Issues](../../issues) or [coordinator@fragmentscreen.org](mailto:coordinator@fragmentscreen.org).

## Attribution

This Code of Conduct is adapted from the Contributor Covenant.
